# Creaking Infection Mod

A Minecraft mod where players transform into a creaking worm and infect the world.

## Features

- Transform into a creaking worm and infect the world
- New biome with unique features
- Infection mechanics for mobs with different stages of infection
- Custom blocks and items
- Sound effects for infection events

## Requirements

- Minecraft 1.20.1
- Forge 47.1.0 or later

1. Download the mod file from the releases page.
2. Place the mod file in the `mods` folder of your Minecraft instance.
